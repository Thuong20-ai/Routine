# Routine Dashboard — Research áo thun in hình

Dashboard một file (HTML + JS + CSS, dữ liệu nhúng sẵn) tổng hợp research: collection mới nên in hình gì, bán giá nào.

## Xem online (GitHub Pages)
1. Vào **Settings → Pages**
2. Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. Sau ~1 phút, truy cập `https://<username>.github.io/<tên-repo>/`

## Chạy local
Mở thẳng `index.html` bằng trình duyệt (cần internet để tải font Google và thư viện ECharts qua CDN).

## Ghi chú
- File ~2.3 MB do ảnh được nhúng base64.
- Không có bước build, không có dependency.
